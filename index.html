First-time setup with your own Google Sheet
  1. Create a Google Sheet, then open Extensions › Apps Script.
  2. Tap Copy backend script above. Paste it over everything in the editor and save. A private token is generated for you and already filled in.
  3. Deploy › New deployment › Web app. Execute as Me, access Anyone. Approve the permissions and copy the Web app URL.
  4. Paste the URL above and tap Save connection.
  5. On your other devices, enter the same URL and the token from the SECRET line in Apps Script.
